# Okno informacji o AmberBim

## Zachowanie
- Polecenie Info otwiera modalne okno WPF z biblioteką WPF UI.
- Właścicielem okna jest główne okno Revita.
- Okno wyświetla nazwę AmberBIM Tools i wersję 0.3.
- Copyright obejmuje lata od 2020 do bieżącego roku
  kalendarzowego, ustalanego przy otwieraniu okna.
- Okno zawiera nazwisko Mateusz Amber Ambrożewicz
  oraz odnośnik do https://amberbim.wordpress.com.
- Odnośnik otwiera domyślną przeglądarkę Windows.
- Okno można zamknąć przyciskiem Zamknij lub klawiszem Escape.
- Zamknięcie okna kończy polecenie wynikiem Result.Succeeded.

## Wersjonowanie i zgodność
- AssemblyVersion i AssemblyFileVersion wynoszą 0.3.0.0.
- Manifest dodatku wskazuje wersję 0.3.
- Okno i jego zależności obsługują wszystkie konfiguracje Revita 2021–2027.
